The independent review found a security gap in this otherwise successful cycle: the Bazzite state records `signature: containerPolicy`, while the six ForjaOS states have no `signature` field. The controller used `bootc switch` without `--enforce-container-sigpolicy`, contrary to NFR-023 and ADR-030. The [bootc switch manual](https://bootc.dev/bootc/man/bootc-switch.8.html) documents the enforcement flag. This run proves the functional transitions, but not signature enforcement by bootc. The PR remains draft and the review gate remains open pending a scoped test of policy-verified switch and upgrade.

The maintainer separately authorized, on 2026-11-11 under AGENTS.md rule 7, only the disposable Bazzite CI VM to add the ForjaOS public key and a `sigstoreSigned` rule for `ghcr.io/forjaos-project` to its existing `/etc/containers` policy. The prepared correction preserves Bazzite's policy rules, rejects an unsafe or conflicting base policy, enables signature discovery for this namespace, switches with enforcement, and requires `containerPolicy` in every state JSON. It has 136 passing local Python tests; a new real VM run is required before it can satisfy NFR-023.
