The complete Bazzite → switch → upgrade → rollback cycle has not yet run successfully on a GitHub-hosted runner. The controller and its state assertions passed locally with fake transports, but those tests are not VM evidence.

- [Run 43032461929](https://github.com/forjaos-project/forjaos/actions/runs/43032461929) on Ubuntu 24.04 reached `bcvk libvirt run` and failed before VM creation with `crun: setns mnt: Bad file descriptor`.
- [Run 43034197467](https://github.com/forjaos-project/forjaos/actions/runs/43034197467) on Ubuntu 26.04 was cancelled after two attempts; both runners failed to resolve Ubuntu package mirrors during host-tool installation.
- [Run 43037770639](https://github.com/forjaos-project/forjaos/actions/runs/43037770639) returned to Ubuntu 24.04 with a direct Podman runtime probe, but its runner also failed to resolve `azure.archive.ubuntu.com` before reaching the probe.
- [Run 43038682930](https://github.com/forjaos-project/forjaos/actions/runs/43038682930) fails early when the Ubuntu mirror cannot be resolved. Both attempts stopped before installing host tools or starting a VM.

Therefore the FR-008 CI acceptance gate remains open, and PR #45 must remain a draft. A successful CI artifact containing the seven `bootc status --json` states is required before review and ship.
