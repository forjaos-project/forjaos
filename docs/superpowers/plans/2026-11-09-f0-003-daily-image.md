# F0-003 Daily Image Workflow Implementation Plan

**Goal:** Build both ForjaOS bootc variants daily, test them before publication, sign an immutable digest with the existing cosign key, and expose `:testing` only after verification (ADR-002, ADR-030, NFR-040).

**Architecture:** A Bash entry point in `.github/scripts/` accepts one of the two image names. It chooses the ADR-0032 base, builds locally with Podman, runs `bootc container lint`, checks FR-003 identity and runs the F0-004 branding checker. A passing image is pushed under a temporary candidate tag; cosign signs and verifies its digest using the repository secret in memory. Skopeo copies that same digest to `:testing` with digest preservation, followed by a remote digest and signature check. The Actions workflow schedules daily runs, permits manual dispatch, and runs the variants in a matrix. A separate issue-writing job records any failed matrix run. A currently branded image fails before registry publication; F1-011 owns image rebranding (FR-002).

**Tech Stack:** GitHub Actions, Bash, Podman and Skopeo from Ubuntu packages, cosign from the existing pinned installer action, Python standard-library structural tests. Podman and Skopeo are Apache-2.0 tools; they are installed only on the ephemeral runner, with no added repository or image package (ADR-002, G4).

**Entry:** Issue #22 provides the ADR-002/NFR-040 scope and objective DoD. `F0-003` is claimed on the remote branch, with F0-001 and F0-002 complete.

## File map

- `.github/scripts/daily-image.sh` — per-variant build, prepublication tests, candidate push, digest signing and promotion.
- `scripts/tests/test_daily_image.sh` — fake Podman/Skopeo/cosign and checker to prove command order, both variants, and fail-closed behavior.
- `.github/workflows/daily-image.yml` — scheduled/manual matrix and failure-reporting job.
- `scripts/tests/test_daily_image_workflow.py` — workflow triggers, matrix, permissions, pinning, gates, and failure-issue assertions.
- `docs/roadmap/roadmap.json` — only the already-claimed F0-003 item, moved to `done` at ship.
