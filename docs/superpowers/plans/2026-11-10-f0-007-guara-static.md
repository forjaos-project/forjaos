# F0-007 Static Guará Mascot Plan

**Goal:** Deliver five deterministic, layered SVG states of the Guará mascot, following the approved geometric concept and the palette contract (FR-054, ADR-027).

**Architecture:** A small Python generator reads `brand/palette.json`, draws a common 512×512 silhouette with stable group IDs, and changes only state-specific eyes, mouth, glow, and badge geometry. Versioned SVGs are generated artifacts; `--check` detects drift. The preview triptych is design evidence, not a runtime asset.

**Tech Stack:** Python standard library, SVG 1.1, existing ImageMagick in the Fedora base for review PNGs, `unittest`, and the existing token checker. No runtime dependency or repository is added. Art uses the project's CC BY-SA 4.0 policy; generator code uses Apache-2.0 (ADR-007, G4).

**Entry:** F0-007 was claimed and pushed on `feat/F0-007-guara-static`. The design source is `docs/superpowers/specs/2026-11-10-guara-static-design.md`; the approved direction is A from the concept preview. The plasmoid screen spec hash passed `gen_tela_specs.py --check`. This item produces assets, not the plasmoid screen (FR-054).
