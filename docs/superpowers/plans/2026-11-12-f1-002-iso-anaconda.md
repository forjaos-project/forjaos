# F1-002 — ISO Anaconda e integridade — plano

**Goal:** gerar uma ISO Anaconda para cada variante a partir de um digest OCI assinado, medir o limite de 6 GB e preparar a distribuição verificável e o guia de gravação (FR-010, FR-014, NFR-011, ADR-002, ADR-024).

**Architecture:** conforme ADR-0035, o job resolve `:testing` para um digest imutável, verifica sua assinatura com `cosign.pub` e cria um contêiner instalador Fedora separado do payload. O `image-builder generic-iso` produz uma ISO Anaconda interativa com Kickstart que busca esse digest pela rede. A política de assinatura do ambiente instalador rejeita payload sem assinatura válida. Um validador confere tamanho, SHA-256 e assinatura da ISO; o CI prova as duas variantes. A publicação direta no GitHub Release exige cada arquivo < 2 GiB, além de NFR-011 ≤ 6 GB.

**Tech Stack:** Bash, Python standard library, Podman, Skopeo, `image-builder-cli` fixado por digest (Apache-2.0), Fedora bootc fixado por digest como ambiente Anaconda, cosign v3.1.4, GitHub Actions. Nenhuma dependência é adicionada à imagem ForjaOS.

**Fatos de entrada:** FR-010 exige ISO Anaconda por rede, digest OCI assinado e checksum no GitHub Release; FR-014 exige guia e teste com Fedora Media Writer, Ventoy e `dd`; NFR-011 limita a ISO a 6 GB. O GitHub limita cada asset a menos de 2 GiB. O CI anterior mediu 9,94/10,81 GB para a ISO offline. O teste físico dos três métodos é condição de aceite e só será registrado em pendrives de teste.

## Emenda aprovada — ADR-0039 (build local e ISO de teste sem assinatura)

- Gerar e testar as duas variantes no PC do mantenedor; manter ISOs e manifestos no D:. O armazenamento temporário do Podman fica no WSL do C: sob a reserva de espaço do host.
- ISO de teste não recebe assinatura cosign nem vai para uma release candidata. `build-iso.sh` ainda verifica a assinatura do payload ForjaOS usado pelo instalador.
- Assinar a ISO somente no passo final de publicação. Preservar tamanho, checksum, firmware/licenças e validação de boot. Não gravar o arquivo ISO no histórico Git.
- Esta emenda substitui as tarefas antigas que exigiam assinatura de ISO candidata ou release `rc.N`; demais requisitos de FR-010 e FR-014 permanecem.
