# F1-006 Plasma Theme and Branding Gate Plan

**Goal:** Replace inherited visible Plasma, wallpaper, KDE profile, and icon branding with the ForjaOS dark/light desktop, layout, and shortcuts so both image variants pass FR-002 and FR-050/052/055/058.

**Architecture:** Generate wallpaper and theme assets from `brand/palette.json`, install them as an RPM with exact base-compatible capabilities for the two inherited theme/background RPMs, then apply a narrow `/usr/share` profile overlay for defaults and shortcuts. Keep gaming packages installed while replacing their branded visible assets. The unchanged branding checker is the final image gate. F1-006 is advanced under the maintainer's explicit request to finish issue #25: phase 0 `:testing` is blocked by visual assets assigned to this phase 1 item.

**Tech Stack:** Python standard library and ImageMagick from the existing Fedora base for deterministic 4K assets; Plasma 6 look-and-feel, KConfig, layout JavaScript, RPM spec and `rpmbuild`, Docker image builds, Python and shell tests. Plus Jakarta Sans is distributed from its upstream [OFL-1.1 repository](https://github.com/tokotype/PlusJakartaSans); JetBrains Mono is the official Fedora `jetbrains-mono-fonts` RPM. The new font and package capabilities are justified by FR-050/051 and checked under G4.

**Sources:** `docs/design-system/telas/forjaos_desktop_principal_dock.md`, `docs/design-system/telas/forjaos_desktop_principal_modo_claro_alabaster_forge.md`, `docs/design-system/DESIGN-RULES.md`, `brand/palette.json`, PRD FR-002/050/052/055/058. `gen_tela_specs.py --check` passes. The light prototype lacks `screen.png`; render its `code.html` at 1600×1280 for the comparison before the visual gate.

## File map

- `brand/wallpapers/build_wallpapers.py`, `brand/wallpapers/ForjaOS/` — four 3840×2160 official dark/light × abstract/Guará wallpapers.
- `brand/plasma/` — dark/light color schemes, Forja look-and-feel metadata/defaults, splash, and two-panel layout based on the approved desktop specs.
- `brand/fonts/` — upstream Plus Jakarta Sans font and OFL license, needed for the primary UI family.
- `brand/tests/test_plasma_assets.py` — wallpaper dimensions, palette, SVG, theme metadata, layout, font and shortcut assertions.
- `brand/LICENSES.md` — font and art origin/license entries.
- `image/build_files/forjaos-plasma.spec`, `image/build_files/build_plasma_rpm.sh` — package project assets and satisfy exact capabilities required by the Fedora desktop without removing `plasma-desktop` or `plasma-workspace`.
- `image/build_files/configure_plasma.py` — set defaults in `/usr/share/kde-settings`, replace scoped inherited visible assets, and preserve non-brand gaming files.
- `image/Containerfile` — install the new RPM after `forjaos-branding` and run the profile overlay before `bootc container lint`.
- `scripts/tests/test_plasma_image.py`, `scripts/tests/test_plasma_image.sh` — package transaction, profile and checker integration tests.
- `docs/shortcuts.md` — exact Super+Espaço/T/E/G/M mappings and availability rules.
- `docs/design-system/telas/forjaos_desktop_principal_dock/compare-2026-11-10.png` and `docs/design-system/telas/forjaos_desktop_principal_modo_claro_alabaster_forge/compare-2026-11-10.png` — prototype/implementation visual proof at matching resolution.
- `docs/roadmap/roadmap.json` — only F1-006 changes from `doing` to `done` at ship.
