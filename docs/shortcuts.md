# Atalhos do desktop ForjaOS

| Atalho | Ação | Disponibilidade |
| --- | --- | --- |
| Super+Espaço | Central de Comando do HERO | Reservado para o overlay; será ativado quando o HERO estiver instalado. |
| Super+T | Abrir o Konsole | Ativo no primeiro login via `org.forjaos.terminal.desktop`. |
| Super+E | Abrir o Dolphin | Ativo no primeiro login pelo atalho do Dolphin incluído no KDE. |
| Super+G | Alternar Modo Jogo | Reservado para `hero-game.target` (FR-043); sem comando até a funcionalidade existir. |
| Super+M | Silenciar microfone do HERO | Reservado para o serviço HERO; sem comando até a funcionalidade existir. |

Os três atalhos reservados não executam comandos inexistentes. O usuário pode alterar os atalhos ativos em Configurações do Sistema → Teclado → Atalhos.
